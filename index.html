Evolución del Proyecto por Semanas

Hito 1 · S09 HTML5 Puro

Semana 09: Fundamentos HTML5

Estructura semántica base sin estilos visuales. Se modela la jerarquía de contenidos, tablas, listas y formularios cívicos.

  • ✔️ Etiquetas semánticas: header, nav, main, section, article, aside.
  • ✔️ Formularios completos: campos requeridos, time-pickers y checkboxes.
  • ✔️ Accesibilidad inicial: atributos alt, labels vinculados y legends.
  • ❌ Sin CSS ni JS: renderizado nativo del navegador.

Hito 2 · S10 CSS3 + Responsive

Semana 10: CSS3 & Responsive

Implementación de la identidad visual de RecycleNow, diseño adaptable, componentes visuales, tipografía y paleta ecológica.

  • ✔️ Design System: paleta verde cívica con variables CSS (:root).
  • ✔️ Maquetación moderna: Header Flexbox y Catálogo en CSS Grid.
  • ✔️ Responsive Design: adaptación fluida para móvil, tablet y PC.
  • ❌ Sin JavaScript: interfaz estilizada pero estática.
Ver Avance Semana 10 ↗
Hito 3 · S11 JavaScript Modular

Semana 11: Vanilla JS (Final)

Interactividad completa con JavaScript puro dividido sin colisiones entre los 6 integrantes para las 3 Historias de Usuario.

  • ✔️ HU1: Buscador reactivo, chips, categorías y checklist en cascada.
  • ✔️ HU3: Switch lista/mapa, filtros, favoritos (localStorage) y modal.
  • ✔️ HU2: Time-pickers am/pm y validación de publicación del punto.
  • ✔️ Arquitectura: 6 funciones modulares con defer y sin recargas.
